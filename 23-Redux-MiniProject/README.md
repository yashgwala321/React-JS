# Media X

Media X is a React-based media discovery app where users can search for photos and videos and save their favorite media to a personal collection.

## Features

- Search photos and videos
- Add media to collection
- Remove saved media
- LocalStorage support
- Responsive UI

## Tech Stack

React.js • Redux Toolkit • React Router • Tailwind CSS • Axios • Unsplash API • Pexels API
